## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → Express `/api/generate` | Untrusted `productInfo` / `affiliateLink` cross into the server and are interpolated into the LLM prompt |
| Gemini model → Express | Model output is untrusted data — must be schema-validated before it is returned to the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-00-01 | Tampering | Malformed/renamed-key model output returned to client | high | mitigate | `responseSchema` constrains shape + `GeneratedContentSchema.safeParse` double-guard before `res.json` (D-02/D-03); invalid shape → non-2xx, never forwarded |
| T-00-02 | Tampering | Oversized/prompt-injection input inflating cost/steering output | medium | mitigate | `express.json({ limit: "32kb" })` caps request body (V5 partial); full input-length/URL validation continues in Plan 02 |
| T-00-03 | DoS | Cost-drain via unthrottled paid Gemini calls (`/api/generate`) | medium | accept | Rate limiting deferred to public-ready phase (PUB-01/PUB-02) per CONTEXT §deferred; documented-accepted, not open |
| T-00-04 | Info Disclosure | `GEMINI_API_KEY` leaking to client/bundle | high | mitigate | Key read from `process.env` server-side only (CLAUDE.md); never sent to client; not needed in CI (D-10) |
| T-00-SC | Tampering | npm/pip/cargo installs (supply chain) | high | mitigate | RESEARCH §Package Legitimacy Audit verified all packages (zod/vitest/supertest/coverage/testing-library/jsdom) as established, high-download, no postinstall — no [ASSUMED]/[SUS] packages requiring a blocking checkpoint |
